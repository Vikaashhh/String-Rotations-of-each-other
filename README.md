## 🔁 Problem: Check if two strings are rotations of each other.
---
💡 Insight:
Two strings are rotations if:

- They are of the same length, and

- One is a substring of the other concatenated to itself (s1 + s1).
---
## 🧠 Approach (in simple steps):

1. ✂️ Check if lengths are equal.

2. 🔗 Concatenate the first string with itself.

3. 🔍 See if the second string is a substring of this new string.

## 🔍 Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
